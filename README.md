## 📡 Prime Resonance Scanner (PRS) v1.4
A High-Aperture Interferometer for the Number Field
The Prime Resonance Scanner is a computational implementation of the Spectral Interpretation of the Riemann Zeta Function. 
Rather than utilizing traditional trial division or probabilistic primality tests, 
the PRS treats prime numbers as constructive interference events within a wave field generated by the non-trivial zeros of the Riemann Zeta function.
